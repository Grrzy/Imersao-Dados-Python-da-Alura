# Imersão-Dados-Python-da-Alura

 Este é um app desenvolvido de forma guiada durante uma imersão da Alura, onde foi explorado a criação de Dashboard de Análise de Salários na Área de Dados via Python.
 *Os dados foram disponibilizados pela Alura para o exemplo

  O app está hospedado para visualização na plataforma Streamlit, pelo link:
